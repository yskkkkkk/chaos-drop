# 🎯 Pinball Rivals (네온 핀볼 구슬 경주)

> **2D 리얼타임 물리 엔진과 화려한 네온 비주얼, 고품격 카메라 연출이 결합된 웹 기반 구슬 경주 추첨 시스템입니다.**
> 기존의 거대한 단일 파일 코드를 유지보수가 용이하도록 깨끗하게 [HTML, CSS, JS] 모듈 구조로 완전히 재구축했습니다.

---

## 🎨 주요 특징 (Features)

1. **리얼타임 2D 물리 엔진**: 순수 JavaScript 탄성 충돌, 중력 가속도, 벽면 반사 및 마찰 연산이 적용된 아케이드 핀볼 시스템.
2. **반응형 모바일 UI 완벽 지원**: 데스크탑 화면 외에도 모바일 뷰포트(≤ 768px)에서 직관적인 2-Step Wizard 설정창, 미니 리더보드 오버레이, 그리고 모바일 전용 물리 보드 스케일링(`BOARD_XSCALE`)을 지원합니다.
3. **모니터 주사율 독립 60FPS 제한 (FPS Lock)**: 144Hz/240Hz 등의 게이밍 고주사율 모니터에서도 60Hz 보급형 노트북과 동일한 속도로 차분하게 굴러가는 안정성 보장.
4. **Multi-target Framing & Smooth Zoom**: 선두 경쟁 구도, 탈락 위기 구도, 특정 순위 목표 구도 등 선택한 룰에 최적화된 동적 카메라 연산 및 흔들림(Jitter) 없는 무빙.
5. **유리 카드 제어 패널 (Glassmorphism UI)**: 현대적이고 세련된 다크 글래스모피즘 테마를 적용해 참전 명단, 당첨 순위 규칙 및 모드 조절 가능.
6. **스마트 랭킹 카메라 (PC 인게임 HUD)**: 레이싱 중 승부에 가장 중요한 등수 그룹(타겟 그룹)만 실시간으로 집중 중계하는 슬림한 사이드바 HUD.
7. **VAR Photo-Finish 판독 시스템**: 결승선 도달 순간 초당 프레임을 팽창시켜 8배 느린 정밀 슬로우 비디오로 최종 순위를 가려내는 정밀 비디오 보조 판정.
8. **자동 최적화 모드 (LOW-END MODE)**: PC 프레임 저하 감지 시 실시간 글로우 차단 및 모바일 자동 이펙트 조절 기능 탑재.

## 📂 모듈화된 프로젝트 구조 (Architecture)

프로젝트 코드는 관심사 분리(Separation of Concerns) 설계 원칙에 따라 다음과 같이 깔끔하게 쪼개어져 있습니다.

*   📂 **`index.html`**: 모든 HTML5 레이아웃 마크업, 리더보드 테이블 구조 및 최종 팝업 모달이 정의된 메인 진입점입니다.
*   📂 **`manifest.json`** & **`service-worker.js`**: PWA 오프라인 캐싱 및 설치 명세서. (보안 정책상 루트에 위치)
*   📂 **`assets/`**: PWA 아이콘 및 Open Graph 메타데이터 프리뷰 이미지 등 정적 자원.
*   📂 **`css/`**: 
    *   `style.css`: AWS 오렌지 테마, Glassmorphism 카드 레이아웃, 인게임 HUD 전환 트랜지션, 반응형 미디어 쿼리 등을 관리하는 스타일시트.
*   📂 **`js/`**: 핵심 로직 및 클래스 모듈
    *   `constants.js`: 중력 상수(`GRAVITY`), 마찰 저항, 줌 한계 및 모바일 스케일링 계수 등 정적 파라미터.
    *   `game.js`: 구슬 레이싱의 코어 엔진 스크립트로서, 렌더링 애니메이션 루프 및 맵 기동을 조율.
    *   `ui.js`: 참가자 태그(칩) 관리, 스태퍼 조작, 맵 전환 및 UI 인터랙션 전담.
    *   `hud.js`: PC 환경 인게임 전용 미니 HUD (스마트 랭킹 카메라 로직) 제어.
    *   `ball.js`: 경주용 구슬의 물리 동역학 및 스핀 연출, 완주 공의 고스트 드로잉.
    *   `collision.js`: 구슬과 장애물(핀, 범퍼 등) 및 벽과의 2D 탄성 충돌 반사 연산 처리.
    *   `camera.js`: 선두 추적, VAR, Near Miss 드라마 구현을 위한 줌/스크롤 모션 관리.
    *   `entities.js`: 핀, 범퍼, 와류, 텔레포트 포탈, 아이템(쉴드, 부스터) 물리 객체 클래스 보관.
    *   `race.js`: 완주 구슬 등록, VAR 판정 기준 검사, 당첨자 모달 팝업 판정.
    *   `sound.js`: 웹 오디오 API 기반 효과음(충돌, 골인, 런치 등) 기능 수행.
    *   `effects.js`: 파티클 폭죽(Confetti) 및 Near Miss 불꽃 스파크 방출 효과 렌더링.
    *   `physics.js`: 2D 중력 및 공기 저항 물리 공식 유틸리티.
*   📂 **`maps/`**: 개별 맵 설정들이 들어있는 디렉토리.
    *   `neon.js`: 블랙홀 함정과 터널 가속 주로 중심의 맵
    *   `canyon.js`: 구불구불한 협곡 지형 모핑, 주기적 강물 역류 및 아이템 중심 서바이벌 맵
*   📂 **`docs/`**: 프로젝트 상세 기술 정보가 기록된 디렉토리.
*   📂 **`backup_pinball_game.html`**: 모듈화 이전의 거대 단일 소스 원본의 히스토리 아카이브.

## 🚀 실행 및 플레이 방법 (Running the Game)

이 프로젝트는 Docker나 NPM 의존성 패키지 설치 없이 **순수 바닐라 웹 기술**로만 구성되어 있어 매우 쉽고 빠르게 로컬 가동이 가능합니다.

### 방법 1. 브라우저로 직접 실행
*   프로젝트 폴더 내의 `index.html` 파일을 마우스 더블클릭하여 브라우저로 열면 즉시 실행됩니다.

### 방법 2. 가벼운 정적 웹서버 실행
터미널에 VS Code 또는 PowerShell을 열고 아래 명령 중 하나를 입력해 로컬 서버를 띄울 수 있습니다:

```bash
# Python3가 설치되어 있는 경우
python -m http.server 8000

# Node.js가 설치되어 있는 경우 (npx 활용)
npx http-server -p 8000
```
웹 브라우저 주소창에 `http://localhost:8000`을 입력하여 접속합니다.

## ⚖️ 게임 규칙 설정 가이드

1. **👑 선착순 당첨**: 가장 먼저 골인한 `N`명 당첨 (예: 커피 내기 1등 뽑기)
2. **🛡️ 후착순 당첨**: 가장 오래 걸려서 꼴찌로 골인한 `N`명 당첨 (예: 청소 당번 벌칙 뽑기)
3. **🎯 특정 순위 당첨**: 정확히 지정한 `K`번째 골인자 단 1명만 당첨 (예: 징검다리 럭키 골인)
4. **❄️ FREEZE MODE**: 맵 하단 30% 영역에서 확률적으로 구슬들이 프리즈 상태(무중력 호버링)에 빠져, 대규모 리버스 역전 드라마를 장식합니다.
