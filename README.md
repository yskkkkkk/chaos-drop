# Chaos Drop (Pinball Rivals)

Chaos Drop은 물리 엔진을 기반으로 한 우당탕탕 무작위 핀볼 당첨 레이싱 웹 게임입니다.  
참가자 명단을 입력하고 당첨 룰(선착순, 후착순, 특정순위)을 정해 핀볼 경주를 통해 당첨자를 뽑습니다.

## 기능 (Features)
- **다양한 당첨 룰**: 선착순, 후착순, 특정 등수 단독 당첨 모드
- **물리 엔진 맵**: 네온(Neon), 협곡(Canyon) 등 동적이고 찰진 물리 작용이 있는 다양한 맵
- **크로스 플랫폼**: 데스크톱과 모바일에 최적화된 PWA 환경 제공 (오프라인 캐싱 지원)
- **스마트 랭킹 카메라 (PC 인게임 HUD)**: 레이싱 중 승부에 가장 중요한 등수 그룹(타겟 그룹)만 실시간으로 집중 중계하는 슬림한 HUD
- **자동 최적화 모드 (LOW-END MODE)**: PC 렉 감지 시 실시간 글로우 차단 및 모바일 자동 이펙트 조절 기능

## 디렉터리 구조 (Directory Structure)

본 프로젝트는 유지보수의 편의성을 위해 기능별로 모듈화된 폴더 구조를 가집니다.

```
chaos-drop/
├── index.html              # 게임 메인 진입점 (설정 UI 및 캔버스)
├── manifest.json           # PWA 웹앱 매니페스트
├── service-worker.js       # PWA 오프라인 구동용 캐싱 워커 (루트 디렉터리 위치 필수)
├── AI.md                   # AI 에이전트를 위한 컨텍스트 및 시스템 룰
├── README.md               # 프로젝트 개요 및 디렉터리 명세
│
├── assets/                 # 이미지 자산
│   ├── icon-192.png        # PWA 아이콘 (192px)
│   ├── icon-512.png        # PWA 아이콘 (512px)
│   └── og-image.png        # Open Graph 메타데이터 프리뷰 이미지
│
├── css/                    # 스타일시트
│   └── style.css           # 전체 앱 스타일, 모달, HUD, 반응형 레이아웃 관리
│
├── js/                     # 핵심 로직 및 클래스 모듈
│   ├── ball.js             # 구슬(참가자) 객체 (이동, 궤적, 렌더링)
│   ├── camera.js           # 맵 뷰포트 추적 (선두/타겟/전체 보기) 카메라 로직
│   ├── collision.js        # 객체 간 충돌 감지 및 물리 반발력 연산
│   ├── constants.js        # 물리 계수, 마찰력, 중력, 크기 등 전역 상수 정의
│   ├── effects.js          # 충돌 시 발생하는 스파크, 파티클 이펙트
│   ├── entities.js         # 맵 구성 요소 (벽, 핀, 범퍼, 포털, 슬라임 등)
│   ├── game.js             # 메인 게임 루프 및 캔버스 초기화, 상태 관리
│   ├── hud.js              # PC 환경 인게임 전용 미니 HUD (스마트 랭킹) 로직
│   ├── physics.js          # 물리 연산 헬퍼 (유틸리티)
│   ├── race.js             # 레이싱 진행 상황, 순위 계산, 당첨자 판정, 결과 모달
│   ├── sound.js            # Web Audio API 기반 효과음 (BGM, 충돌, 스윕 등)
│   └── ui.js               # index.html의 설정 패널 및 입력창 이벤트 핸들링
│
├── maps/                   # 맵 지형 데이터 스크립트
│   ├── canyon.js           # 폭포와 진흙탕이 있는 자연 계곡 테마 맵
│   └── neon.js             # 점프 패드와 포털이 있는 네온 글로우 테마 맵
│
└── docs/                   # 기타 문서
```

## 실행 방법
따로 빌드 과정이 필요 없는 Vanilla JS 프로젝트입니다.
VS Code의 Live Server나 Python의 `python -m http.server` 등을 통해 루트 폴더를 서빙하면 바로 실행할 수 있습니다.
