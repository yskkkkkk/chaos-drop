# 🎯 Pinball Rivals (네온 핀볼 구슬 경주)

> **2D 리얼타임 물리 엔진과 화려한 네온 비주얼, 고품격 카메라 연출이 결합된 웹 기반 구슬 경주 추첨 시스템입니다.**
> 기존의 거대한 단일 파일 코드를 유지보수가 용이하도록 깨끗하게 [HTML, CSS, JS] 모듈 구조로 완전히 재구축했습니다.

---

## 🎨 주요 특징 (Features)

1. **리얼타임 2D 물리 엔진**: 순수 JavaScript 탄성 충돌, 중력 가속도, 벽면 반사 및 마찰 연산이 적용된 아케이드 핀볼 시스템.
2. **반응형 모바일 UI 완벽 지원 (New!)**: 데스크탑 화면 외에도 모바일 뷰포트(≤ 768px)에서 직관적인 2-Step Wizard 설정창, 미니 리더보드 오버레이, 그리고 모바일 전용 물리 보드 스케일링(`BOARD_XSCALE`)을 지원합니다.
3. **모니터 주사율 독립 60FPS 제한 (FPS Lock)**: 144Hz/240Hz 등의 게이밍 고주사율 모니터에서도 60Hz 보급형 노트북과 동일한 속도로 차분하게 굴러가는 안정성 보장.
4. **Multi-target Framing & Smooth Zoom**: 선두 경쟁 구도, 탈락 위기 구도, 특정 순위 목표 구도 등 선택한 룰에 최적화된 동적 카메라 연산 및 흔들림(Jitter) 없는 무빙.
5. **유리 카드 제어 패널 (Glassmorphism UI)**: 현대적이고 세련된 다크 글래스모피즘 테마를 적용해 참전 명단, 당첨 순위 규칙 및 모드 조절 가능.
6. **VAR Photo-Finish 판독 시스템**: 결승선 도달 순간 초당 프레임을 팽창시켜 8배 느린 정밀 슬로우 비디오로 최종 순위를 가려내는 정밀 비디오 보조 판정.

## 📂 모듈화된 프로젝트 구조 (Architecture)

프로젝트 코드는 관심사 분리(Separation of Concerns) 설계 원칙에 따라 다음과 같이 깔끔하게 쪼개어져 있습니다.

*   📂 **`index.html`**: 모든 HTML5 레이아웃 마크업, 리더보드 테이블 구조 및 최종 팝업 모달이 정의된 메인 진입점입니다.
*   📂 **`style.css`**: AWS 오렌지 테마, Glassmorphism 카드 레이아웃, 반응형 미디어 쿼리, 카드 팝업 키프레임 애니메이션 등을 관리하는 스타일시트입니다.
*   📂 **`constants.js`**: 중력 상수(`GRAVITY`), 마찰 저항, 줌 한계 및 모바일 스케일링 계수 등 **정적 튜닝 파라미터**를 집중 관리합니다.
*   📂 **`game.js`**: 구슬 레이싱의 코어 엔진 스크립트로서, 메인 렌더링 애니메이션 루프 및 맵 기동을 조율합니다.
*   📂 **`ui.js`**: 참가자 태그(칩) 관리, 스태퍼 조작, 맵 전환 및 모바일 2-Step 마법사 UI 동작 등 사용자 인터랙션을 전담합니다.
*   📂 **`ball.js`**: 경주용 구슬의 물리 동역학 및 굴러가는 스핀 연출, 완주 공의 그레이 고스트 드로잉 등을 다룹니다.
*   📂 **`collision.js`**: 구슬과 장애물(핀, 범퍼, 회전 스피너 등) 및 맵 협곡 벽과의 2D 탄성 충돌 반사 연산을 처리합니다.
*   📂 **`camera.js`**: 선두 추적 및 깻잎 한 장 차이 VAR, Near Miss 드라마 지대 구현을 위한 줌/스크롤 카메라 모션을 관리합니다.
*   📂 **`entities.js`**: 핀, 범퍼, 와류, 발사대, 텔레포트 포탈, 가속 패드, 아이템(쉴드, 부스터) 등 게임 내 모든 물리 객체들의 클래스 정의를 보관합니다.
*   📂 **`race.js`**: 완주 구슬 등록, VAR 판정 기준 검사, 실시간 스코어보드 렌더링 및 당첨자 모달 팝업 처리를 담당합니다.
*   📂 **`sound.js`**: 웹 오디오 API 기반의 효과음(충돌, 골인, 런치 등) 및 음소거 토글 기능을 수행합니다.
*   📂 **`effects.js`**: 결승선 통과 시의 파티클 폭죽(Confetti) 및 Near Miss 불꽃 스파크 방출 효과를 렌더링합니다.
*   📂 **`physics.js`**: 2D 중력 및 공기 저항 물리 공식 유틸리티를 정의합니다.
*   📂 **`maps/`**: 개별 맵 설정들이 들어있는 디렉토리입니다.
    *   `neon.js`: 중앙 집중형 블랙홀 함정과 터널 가속 주로 중심의 클래식 맵
    *   `canyon.js`: 구불구불한 협곡 지형 모핑, 주기적 강물 역류 및 방어막/부스터 아이템 중심의 서바이벌 맵
*   📂 **`docs/`**: 프로젝트 상세 기술 정보가 기록된 디렉토리입니다.
    *   `ISSUE_LOG.md`: 고주사율 프레임 폭주 등 정밀 타격하여 해결한 기술 이슈 요약서
    *   `MAP_GUIDE.md`: 레지스트리 기반 신규 맵 작성 및 추가 방법 기술서
    *   `MOBILE_PLAN.md`: 모바일 뷰포트 최적화 및 2-Step Wizard 구현 계획 및 이력서
*   📂 **`backup_pinball_game.html`**: 모듈화 이전의 거대 단일 소스 원본의 히스토리 보존을 위한 아카이브 파일입니다.

## 🚀 실행 및 플레이 방법 (Running the Game)

이 프로젝트는 Docker나 NPM 의존성 패키지 설치 없이 **순수 바닐라 웹 기술**로만 구성되어 있어 매우 쉽고 빠르게 로컬 가동이 가능합니다.

### 방법 1. 브라우저로 직접 실행
*   프로젝트 폴더 내의 [index.html](file:///d:/chaos-drop/index.html) 파일을 마우스 더블클릭하여 크롬, 엣지, 사파리 등의 브라우저로 열면 즉시 실행됩니다.

### 방법 2. 가벼운 정적 웹서버 실행
터미널에 VS Code 또는 PowerShell을 열고 아래 명령 중 하나를 입력해 로컬 서버를 띄울 수 있습니다:

```bash
# Python3가 설치되어 있는 경우
python -m http.server 8000

# Node.js가 설치되어 있는 경우 (npx 활용)
npx http-server -p 8000
```
웹 브라우저 주소창에 `http://localhost:8000`을 입력하여 접속합니다.

## ⚖️ 게임 규칙 설정 가이드

1. **👑 선착순 당첨**: 가장 먼저 골인한 `N`명 당첨 (예: 커피 내기 1등 뽑기)
2. **🛡️ 후착순 당첨**: 가장 오래 걸려서 꼴찌로 골인한 `N`명 당첨 (예: 청소 당번 벌칙 뽑기)
3. **🎯 특정 순위 당첨**: 정확히 지정한 `K`번째 골인자 단 1명만 당첨 (예: 징검다리 럭키 골인)
4. **❄️ FREEZE MODE**: 맵 하단 30% 영역에서 확률적으로 구슬들이 프리즈 상태(무중력 호버링)에 빠져, 강한 튕김과 함께 탈출하여 대규모 리버스 역전 드라마를 장식합니다.
